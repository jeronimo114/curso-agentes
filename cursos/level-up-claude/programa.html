Level Up
con Claude

Aprende a construir con IA de verdad. En 3 sesiones lanzas una marca de café desde cero: de la idea al sitio web publicado y conectado a su base de datos.

3 sesiones · 4 h c/u 22 ago · 29 ago · 5 sep 2026 Presencial · Medellín 100% práctico Sin saber programar

De qué va el curso

Casi todo el mundo ya usa la IA para preguntar. Este curso te lleva al siguiente nivel: usar la IA para construir. Aprendes a manejar las herramientas fundamentales de Claude —Chat, Cowork, Design y Code— trabajando sobre un solo proyecto real que crece sesión a sesión.

Ese proyecto es lanzar una marca de café colombiano desde cero: investigar el mercado, estudiar a la competencia, diseñar la marca, construir el sitio web y publicarlo en internet. Al final no te llevas teoría: te llevas algo funcionando, y el método para volver a hacerlo con cualquier idea tuya.

Qué vas a aprender

  • Las herramientas fundamentales de Claude: Chat, Cowork, Design y Code, y cuándo usar cada una.
  • Prompting efectivo y Markdown para darle el mejor contexto al modelo.
  • Investigar un mercado y analizar a la competencia con IA.
  • Diseñar una marca y un manual de marca para web y redes.
  • Construir y publicar un sitio web real con base de datos.
  • Crear tus propias herramientas internas para trabajar mejor con IA.

Cómo funciona

La dinámica

Tres sesiones de cuatro horas, 100% prácticas: aprendes construyendo. Todo gira en torno a un mismo proyecto, y cada sesión deja entregables concretos que alimentan la siguiente.

Presencial y con acompañamiento de los instructores en cada paso.

Para quién es

Para perfiles de negocio y técnicos por igual. No necesitas saber programar: las herramientas están pensadas para que cualquiera construya.

Ideal para emprendedores, marketers, líderes y equipos que quieren pasar de usar la IA a crear con ella.

Con qué sales

  • Una tienda de café funcional y publicada en internet, con su base de datos.
  • Un manual de marca reutilizable para web y redes sociales.
  • Un método y un kit de prompts y herramientas para seguir construyendo lo que quieras.
Qué hacemos cada día

El curso es un solo proyecto que avanza sesión a sesión. Cada día construye sobre los entregables del anterior. Los tiempos son aproximados.

Día 1 22 ago Claude Web · Chat

Contexto, prompting y primer research

Entender la herramienta, aprender a hablarle bien al modelo y hacer la primera investigación en el chat.

  • ~1 hContexto y modelosDe dónde viene la IA generativa, su historia hasta 2022 y sus usos (asistentes especializados / GPTs / proyectos, agentes, programación, automatizaciones). Diferencias entre ChatGPT, Claude y Gemini, y dónde estamos parados.
  • ~1 hPrompting + MarkdownCómo construir buenos prompts, distintos modelos de prompting, y por qué Markdown es clave para darle contexto al modelo.
  • breakDescansoCierre de la parte conceptual (las primeras dos horas).
  • ~1 hExplicación del proyectoPresentamos a fondo el caso: la marca de café. Es lo que motiva todo el curso, así que se explica muy bien.
  • ~30 minReto en chatInvestigación profunda del mercado del café usando los prompts aprendidos, y un Artifact para visualizar los resultados.
Entregable Documentos en Word con el análisis de contexto y de mercado, más un Artifact de visualización. Esta base alimenta todo lo que sigue.
Día 2 29 ago Claude Cowork · Design

Investiga a la competencia y diseña tu marca

Pasar del chat a Cowork para investigar a fondo, construir herramientas propias y diseñar la marca.

  • ~1 hQué es Cowork (y Cowork vs Code)Contextualización y alcance. Cowork es más seguro para perfiles no técnicos y tareas que no son de programación (investigación, recopilación y análisis de datos); Code se usa para tirar código y correr comandos en terminal.
  • ~1 hAnálisis web de competidoresCon Cowork: entrar a los sitios de los referentes, tomar screenshots y usar computer use y el conector web para recopilar todo.
  • ~30 minHerramientas internas en HTMLConstruir herramientas propias para darle mejor contexto al modelo (por ejemplo, puntuar una UI sección por sección, o un guion con inputs por línea para dar feedback estructurado).
  • diseñoDiseño de la base de datosPedirle a Claude el diseño y el diagrama entidad-relación de la base de datos (tablas y cómo se conectan), que se construirá en el Día 3.
  • diseñoClaude Design + manual de marcaPrototipar el sitio y crear el manual de marca, que sirve tanto para la web como para redes sociales.
Entregable Análisis de competidores, herramientas internas, manual de marca y el prompt listo para pasárselo a Design y prototipar el sitio.
Día 3 5 sep Claude Code

Construye, despliega y conecta tu tienda

Llevar todo lo anterior a un sitio real, con base de datos, publicado en internet.

  • ~30 minQué es Claude CodeContextualización rápida, orientada a construir el sitio.
  • buildConstruir el sitioLevantar la tienda de café desde cero en Claude Code y desplegar una primera versión para verla en vivo.
  • datosBase de datos en SupabaseCrear la base de datos: Claude entrega los pasos para ir a Supabase y el script SQL; los estudiantes la crean ellos mismos (no se le deja todo al modelo).
  • deployIntegrar y desplegar en VercelConectar el sitio con la base de datos y publicar en Vercel, integrando todo mediante MCP.
Entregable La tienda de café funcional, desplegada con una URL real y conectada a su base de datos.
